Copy `deploy/.env.example` to `deploy/.env`, generate secrets with `openssl rand -base64 24`, then `cd deploy && docker compose up -d --build`. The dev environment (`backend/docker-compose.yml`) must be stopped first because it shares ports 5432/3000 on the host Mac. Daily backups run at `BACKUP_HOUR` (default 03:00 Colombia time); manual dump via `docker compose exec backup sh /opt/backup/respaldo.sh ahora`; restore via `docker compose exec backup sh /opt/backup/restaurar.sh <dump> <conn>`.
