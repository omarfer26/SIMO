Built on Next.js App Router (`app/` directory) with a two-tier layout: the root `app/layout.tsx` provides global fonts (Geist Sans/Mono via `next/font/google`) and CSS, while `app/(protected)/layout.tsx` wraps every protected route in a `ProductosProvider` (catalog state) and the `Shell` component that composes `Navbar`, `Sidebar`, and `BannerConexion`. Authentication is enforced at the edge via `middleware.ts`, which reads JWT cookies (`token`, `role`) and redirects unauthenticated users to `/login`, plus role-gates `/usuarios` for ADMIN only. The UI layer under `components/` is organized by feature (`admin`, `catalogo`, `dashboard`, `inventario`, `pedidos`, `shell`, `ui`, `usuarios`, `ventas`) with a shared primitive set in `components/ui/` (Button, Modal, DataTable, Campo, etc.). Business logic and API calls live under `lib/<feature>/` (auth, clientes, dashboard, inventario, pedidos, pos, ventas, red), all sharing a single Axios instance in `lib/apiClient.ts` that injects the Bearer token from cookies and clears session on 401/403. Feature pages are thin Route Handlers under `app/(protected)/<feature>/page.tsx` delegating rendering to their corresponding components.
