Three sibling services are wired together at the repo root: `backend` (Express + PostgreSQL) exposes `/api/*` routes consumed by `simoapp` (Next.js App Router), while `docker-compose.yml` in `deployment_infra` runs both services plus PostgreSQL and a Cloudflare tunnel locally. The root `package.json` uses `concurrently` to boot dev servers for both children via `npm run dev`, and `railway.json` / `render.yaml` declare cloud deployments that build the backend with a Dockerfile and start it on port 3000 with a `/api/health` readiness probe.
